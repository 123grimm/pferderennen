# Pferderennen UI

Kleine Vollbild-Weboberflaeche mit farbigen Punkten, die auf mehreren Bahnen zufaellig Richtung Ziellinie rennen.

## Verhalten

- Ueberschrift `Pferderennen`
- Start-Button fuer das Rennen
- Mehrere farbige Punkte bewegen sich fluessig von links nach rechts
- Die Geschwindigkeiten aendern sich waehrend des Rennens, dadurch sind Ueberholmanoever moeglich
- Genau ein Sieger wird erzeugt
- Nur die ersten drei fahren komplett ueber die Ziellinie
- Danach wird der Gewinner angezeigt

## Starten

Einfach `index.html` im Browser oeffnen.

Falls du lokal einen kleinen Server nutzen willst, funktioniert zum Beispiel in diesem Ordner:

```powershell
start .\index.html
```
